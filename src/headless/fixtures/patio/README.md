# Los dibujos del patio

Copia de `art/dibujos/` de *El patio* (Khadosh/el-patio, 19 oct 2026), el segundo
juego hecho con PGS, dibujados a mano. Son los casos reales de `readStanding`
(`src/headless/standing.test.ts`, issue #31): el gato en sus tres vistas, el búho,
el sapo y el erizo tienen que contestar que no son una persona parada; la nena,
que sí. No se retocan acá: si cambian en el patio, se vuelven a copiar.
